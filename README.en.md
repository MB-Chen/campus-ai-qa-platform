> **Customizations** (20+ commits, searchable via `git log --author=2818661801`; details in the [Chinese README](./README.md)):
> ① Fixed 3 multi-knowledge-base defects in the retrieval layer (hybrid channel miss / wrong intent fallback / RRF cross-bank ranking bias);
> ② Designed a deterministic 3-tier keyword intent router (covered by test cases) + fixed Embedding cache inconsistency;
> ③ Built 5 campus knowledge bases (294KB student handbook split & indexed) with agent configuration (DeepSeek + bge-m3);
